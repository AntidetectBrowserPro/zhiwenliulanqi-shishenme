# 指纹浏览器是什么，有什么用？

指纹浏览器可以在一台设备上建立多个独立的浏览环境。**如果你每天要在同一网站切换两家店，最实用的功能就是让每家店各自保持登录。**

以免费应用「指纹浏览器」为例，你可以给 A 店和 B 店各建一个环境。下次要查 A 店的订单，直接打开 A 店的环境，就不用先从 B 店退出。

## 为什么开两个标签页还会串号？

同一浏览器里的普通标签页通常共用同一网站的登录数据。在第二个标签页切换账号后，第一个标签页刷新时，也可能显示刚切过去的账号。把两家店放进各自的浏览环境，就能分开保存这两份登录状态。[官方环境教程](https://zwbrowser.com/help/desktop/environments/)

## 在 Windows 上，怎样找回正确的店铺？

1. **建环境。** 在工作台建两个普通环境，分别取名为「A 店－订单」和「B 店－售后」。
2. **分别登录。** 从两行环境各点一次「打开」，进入同一个商家网站。分别登录对应的店铺账号，看一眼网页上的店名。
3. **按店名找窗口。** 收到 A 店的订单号，就回工作台搜「A 店」。窗口还开着，点「定位」；窗口已关闭，点「打开」。[工作台查找教程](https://zwbrowser.com/help/desktop/find-environment/)

## 名字里的“指纹”指什么？

浏览器版本、语言、时区、屏幕尺寸，都是网页可能读到的信息。这些特征组合起来，就可能帮助网站识别浏览器，这就是常说的“浏览器指纹”。如果你的工作是测试网页，也可以用不同环境保存不同设置，例如检查同一笔订单在两个时区分别显示哪一天。[MDN 浏览器指纹说明](https://developer.mozilla.org/en-US/docs/Glossary/Fingerprinting)
